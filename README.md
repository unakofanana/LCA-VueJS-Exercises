# Cooking Masterclass Catalogue

## Project Overview
This is a Vue.js single-page application that displays a cooking course catalogue for Cooking Masterclass. Users can browse courses, view chef details, prices, and skill levels, and save courses to a wishlist.

## Features
- Course catalogue displayed using cards
- Wishlist system with counter
- Sold out indicator for unavailable courses
- Responsive layout for mobile and desktop

## How to Run the Project

```bash
npm install
npm run dev
```
